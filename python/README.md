# Exercícios de Python

Este repositório reúne exercícios práticos desenvolvidos durante meus estudos em **Python**, com foco na consolidação de fundamentos da linguagem e boas práticas de organização de código.

Os exercícios estão organizados em listas, cada uma contendo desafios progressivos.

##▶️ Como executar os exercícios

1. Clone o repositório:
```bash
git clone <url-do-repositorio>
```

Acesse a pasta do exercício desejado:
```bash
cd lista_1/exercicio1
```

Execute o arquivo Python:
```bash
python nome-do-arquivo.py
```

ou (dependendo do sistema):

```bash
python3 nome-do-arquivo.py
```
