# 🟨 Exercícios de Python

Este repositório contém exercícios práticos de **Python**, com foco em **análise de dados** e **machine learning**, desenvolvidos ao longo das aulas e estudos. Os exercícios exploram conceitos fundamentais da linguagem e sua aplicação em problemas reais de dados, como:

- Estruturas de dados (listas, dicionários, tuplas)
- Manipulação de dados com DataFrames
- Limpeza e transformação de dados
- Visualização de dados
- Modelos de Machine Learning
- Avaliação de modelos
- Leitura e tratamento de datasets

O objetivo é consolidar o conhecimento em Python aplicado a dados e criar exemplos reutilizáveis para referência futura.

## 🛠️ Tecnologias utilizadas

1. **Python**

- Linguagem principal do projeto.
- Simples, versátil e amplamente utilizada em ciência de dados e machine learning.

2. **Pandas**

- Manipulação e análise de dados em formato tabular.
- Permite limpeza, transformação e agregação de dados.

3. **NumPy**

- Operações matemáticas e computação numérica eficiente.
- Base para muitas bibliotecas de ciência de dados.

4. **Matplotlib / Seaborn**

- Visualização de dados.
- Criação de gráficos para análise exploratória.

5. **Scikit-learn**

- Biblioteca de machine learning.
- Implementação de algoritmos como regressão, classificação e clustering.

6. **Jupyter Notebook**

- Ambiente interativo para análise de dados.
- Permite combinar código, visualizações e explicações.

7. **Git & GitHub**

- Controle de versão e organização dos exercícios.
- Histórico de evolução e aprendizado.
